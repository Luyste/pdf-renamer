# PDF Invoice Renamer — Project Setup Instruction

## Context

A tool for a single non-technical user to upload scanned PDF invoices (Hungarian
vet-clinic invoices from számlázz.hu, no embedded text layer — pure image scans),
have them OCR'd and parsed automatically, review/correct the suggested filename in
a browser UI, and download the renamed files. Fully hosted on Cloudflare. One user,
low volume (tens of files per session, a few sessions a month).

## Required tech stack — do not substitute any of these

- **Monorepo tool:** Nx
- **Package manager:** Bun (`create-nx-workspace --packageManager=bun`)
- **Python integration:** `@nxlv/python` Nx plugin (uv-backed), NOT poetry
- **Backend/API:** Hono, deployed as a Cloudflare Worker
- **Frontend:** React + Vite, shadcn/ui components (Sidebar, Dialog, AlertDialog,
  Badge, Input, Button), deployed as Worker static assets
- **OCR pipeline:** Python (PyMuPDF + Tesseract via subprocess), wrapped in FastAPI,
  deployed as a Cloudflare Container (Dockerfile), invoked by the Worker
- **Storage:** Cloudflare R2
- **Auth:** Cloudflare Access (single allow-listed email, no custom auth code)

## Setup steps

1. `npx create-nx-workspace@latest renamer --preset=ts --packageManager=bun --nxCloud=skip --interactive=false`
2. `cd renamer && bun add -D @nxlv/python`
3. `bunx nx g @nxlv/python:uv-project ocr-service --directory=apps/ocr-service`
4. Scaffold `apps/worker` as a Hono + Cloudflare Workers app (use `@nx/next`-equivalent
   community Worker generator if available, otherwise a plain Nx `node` application
   type with `wrangler` as the dev/deploy executor — see "Worker app" section below).
5. Scaffold `apps/web` as an `@nx/react` (Vite) application. Initialize shadcn/ui
   inside it (`bunx shadcn@latest init`) and add components: `sidebar`, `dialog`,
   `alert-dialog`, `badge`, `input`, `button`, `sonner` (toast for confirmations).
6. Create `libs/shared-types` as a plain TS library (`bunx nx g @nx/js:lib shared-types`).

## `apps/ocr-service` — Python pipeline

### `apps/ocr-service/extract.py`

```python
"""
extract.py — core pipeline. No web dependencies.

Flow per PDF:
  rasterize region -> preprocess -> OCR -> regex on anchor labels
  -> normalise -> validate -> confidence score -> filename
"""

from __future__ import annotations

import re
import subprocess
import unicodedata
from dataclasses import dataclass, field, asdict
from datetime import date
from difflib import get_close_matches
from pathlib import Path

import pymupdf

# --------------------------------------------------------------------------
# Config
# --------------------------------------------------------------------------

OCR_LANG = "hun+eng"      # falls back to "eng" automatically if hun missing
OCR_DPI = 300             # 200dpi source; 300 render gives tesseract more to chew on

# Regions as fractions of the page (x0, y0, x1, y1).
# Fractions, not pixels, so this survives A4 vs Letter and any DPI change.
# Deliberately generous — a bit of surrounding noise is harmless because we
# anchor on label text, but a clipped digit is fatal.
REGIONS = {
    "invoice": (0.60, 0.19, 1.00, 0.26),
    "dates":   (0.50, 0.25, 1.00, 0.35),
    "customer": (0.03, 0.26, 0.45, 0.35),
}

# Full-page OCR is the fallback when a region anchor fails.
FULLPAGE = (0.0, 0.0, 1.0, 0.55)   # top half only; bottom is stamp + footer noise

DATE_RE = r"(\d{4})\s*[.\-/]\s*(\d{1,2})\s*[.\-/]\s*(\d{1,2})"
INVOICE_RE = r"([A-Z]{2,10})\s*[-–—]\s*(\d{4})\s*[-–—]\s*(\d{1,6})"

# OCR routinely confuses these in all-caps prefixes and digit runs.
DIGIT_FIXES = str.maketrans({"O": "0", "o": "0", "l": "1", "I": "1", "|": "1", "S": "5"})

HUN_FOLD = {
    "á": "a", "é": "e", "í": "i", "ó": "o", "ö": "o", "ő": "o",
    "ú": "u", "ü": "u", "ű": "u",
}


# --------------------------------------------------------------------------
# Result types
# --------------------------------------------------------------------------

@dataclass
class Field:
    value: str | None = None
    raw: str = ""             # what OCR actually returned, for the review screen
    ok: bool = False
    note: str = ""


@dataclass
class Result:
    source: str
    invoice: Field = field(default_factory=Field)
    fulfil_date: Field = field(default_factory=Field)
    customer: Field = field(default_factory=Field)
    filename: str | None = None
    problems: list[str] = field(default_factory=list)
    ocr_dump: dict[str, str] = field(default_factory=dict)

    @property
    def confident(self) -> bool:
        return not self.problems and all(
            f.ok for f in (self.invoice, self.fulfil_date, self.customer)
        )

    def to_dict(self) -> dict:
        d = asdict(self)
        d["confident"] = self.confident
        return d


# --------------------------------------------------------------------------
# OCR
# --------------------------------------------------------------------------

_LANG_CACHE: str | None = None


def ocr_lang() -> str:
    """Use hun+eng if the Hungarian pack is installed, else eng."""
    global _LANG_CACHE
    if _LANG_CACHE is None:
        try:
            out = subprocess.run(
                ["tesseract", "--list-langs"], capture_output=True, text=True, timeout=15
            ).stdout
            _LANG_CACHE = OCR_LANG if "hun" in out.split() else "eng"
        except Exception:
            _LANG_CACHE = "eng"
    return _LANG_CACHE


def render(page: pymupdf.Page, box: tuple[float, float, float, float], dpi: int = OCR_DPI) -> bytes:
    """Render a normalised region of the page to PNG bytes."""
    r = page.rect
    clip = pymupdf.Rect(
        box[0] * r.width, box[1] * r.height, box[2] * r.width, box[3] * r.height
    )
    return page.get_pixmap(dpi=dpi, clip=clip).tobytes("png")


def ocr(png: bytes, psm: int = 6) -> str:
    """Run tesseract on PNG bytes via stdin/stdout. No temp files."""
    p = subprocess.run(
        ["tesseract", "stdin", "stdout", "--psm", str(psm), "-l", ocr_lang()],
        input=png, capture_output=True, timeout=60,
    )
    return p.stdout.decode("utf-8", "replace")


# --------------------------------------------------------------------------
# Parsing
# --------------------------------------------------------------------------

def _norm(s: str) -> str:
    """Strip accents and lowercase — for matching labels only, never values.

    OCR mangles Hungarian accents constantly ('Teljesítés' -> 'Teljesités'),
    so label matching must be accent-blind.
    """
    return "".join(
        c for c in unicodedata.normalize("NFD", s.lower())
        if unicodedata.category(c) != "Mn"
    )


def parse_invoice(text: str) -> Field:
    """Sorszám: PREFIX-YYYY-NNNN. Prefer the line carrying the label."""
    lines = text.splitlines()
    hits = [ln for ln in lines if "sorsz" in _norm(ln)] or lines

    for ln in hits:
        body = re.sub(r"(?i)sorsz\w*\s*:?", " ", ln)
        m = re.search(INVOICE_RE, body.upper())
        if m:
            prefix = re.sub(r"[^A-Z]", "", m.group(1))
            year = m.group(2).translate(DIGIT_FIXES)
            seq = m.group(3).translate(DIGIT_FIXES)
            if not prefix:
                continue
            return Field(f"{prefix}-{year}-{seq}", ln.strip(), True)

    return Field(None, text.strip()[:120], False, "no PREFIX-YEAR-NUMBER pattern found")


def parse_fulfil_date(text: str) -> Field:
    """The 'Teljesítés dátuma' line specifically.

    The page carries three dates (teljesítés / kiállítás / fizetési határidő)
    and they differ. Never take 'the first date on the page'.
    """
    for ln in text.splitlines():
        n = _norm(ln)
        if "teljesit" not in n:
            continue
        m = re.search(DATE_RE, ln)
        if not m:
            continue
        y, mo, d = (int(g) for g in m.groups())
        try:
            dt = date(y, mo, d)
        except ValueError:
            return Field(None, ln.strip(), False, f"impossible date {y}-{mo}-{d}")
        if not (2000 <= y <= date.today().year + 1):
            return Field(None, ln.strip(), False, f"year {y} out of range")
        return Field(dt.isoformat(), ln.strip(), True)

    return Field(None, text.strip()[:120], False, "'Teljesítés dátuma' label not found")


def parse_customer(text: str, roster: list[str] | None = None) -> Field:
    """First real line under the VEVŐ heading, then snap to the roster."""
    lines = [ln.strip() for ln in text.splitlines() if ln.strip()]
    start = 0
    for i, ln in enumerate(lines):
        if _norm(ln).startswith("vev"):
            start = i + 1
            break

    for ln in lines[start:]:
        if re.match(r"^\s*\d", ln):
            continue
        cleaned = re.sub(r"[^\w\s'\-.]", "", ln, flags=re.UNICODE).strip(" .-")
        if len(cleaned) < 3 or not re.search(r"[A-Za-zÁ-ű]", cleaned):
            continue

        if roster:
            hit = get_close_matches(cleaned, roster, n=1, cutoff=0.75)
            if hit:
                note = "" if hit[0] == cleaned else f"matched roster: '{cleaned}'"
                return Field(hit[0], ln, True, note)
            return Field(cleaned, ln, False, "not in customer roster")

        return Field(cleaned, ln, True)

    return Field(None, text.strip()[:120], False, "no name found under VEVŐ")


# --------------------------------------------------------------------------
# Filename
# --------------------------------------------------------------------------

def slug(name: str) -> str:
    """Hungarian name -> ASCII, safe for any filesystem.

    Horváth Ildikó -> Horvath_Ildiko
    """
    out = []
    for ch in unicodedata.normalize("NFC", name):
        low = ch.lower()
        if low in HUN_FOLD:
            rep = HUN_FOLD[low]
            out.append(rep.upper() if ch.isupper() else rep)
        else:
            out.append(ch)
    s = unicodedata.normalize("NFKD", "".join(out))
    s = "".join(c for c in s if not unicodedata.combining(c))
    s = re.sub(r"[^A-Za-z0-9]+", "_", s).strip("_")
    return s


def build_filename(r: Result) -> str | None:
    if not (r.invoice.value and r.fulfil_date.value and r.customer.value):
        return None
    d = r.fulfil_date.value.replace("-", "_")
    return f"{d}-{r.invoice.value}-{slug(r.customer.value)}.pdf"


# --------------------------------------------------------------------------
# Cross-field validation
# --------------------------------------------------------------------------

def validate(r: Result) -> None:
    for label, f in (("invoice no.", r.invoice), ("fulfilment date", r.fulfil_date),
                     ("customer", r.customer)):
        if not f.ok:
            r.problems.append(f"{label}: {f.note or 'not read'}")

    if r.invoice.value and r.fulfil_date.value:
        inv_year = r.invoice.value.split("-")[1]
        if inv_year != r.fulfil_date.value[:4]:
            r.problems.append(
                f"year mismatch: invoice says {inv_year}, date says {r.fulfil_date.value[:4]}"
            )


# --------------------------------------------------------------------------
# Entry point
# --------------------------------------------------------------------------

def process(pdf_path: str | Path, roster: list[str] | None = None) -> Result:
    pdf_path = Path(pdf_path)
    r = Result(source=pdf_path.name)

    with pymupdf.open(pdf_path) as doc:
        if doc.page_count == 0:
            r.problems.append("PDF has no pages")
            return r
        page = doc[0]

        if page.get_text().strip():
            texts = {k: page.get_text() for k in REGIONS}
            r.ocr_dump["_source"] = "embedded text layer"
        else:
            texts = {k: ocr(render(page, box)) for k, box in REGIONS.items()}
            r.ocr_dump["_source"] = f"OCR ({ocr_lang()})"

        r.ocr_dump.update(texts)

        r.invoice = parse_invoice(texts["invoice"])
        r.fulfil_date = parse_fulfil_date(texts["dates"])
        r.customer = parse_customer(texts["customer"], roster)

        if not all(f.ok for f in (r.invoice, r.fulfil_date, r.customer)):
            wide = ocr(render(page, FULLPAGE), psm=4)
            r.ocr_dump["_fullpage_retry"] = wide
            if not r.invoice.ok:
                if (f := parse_invoice(wide)).ok:
                    r.invoice = f
            if not r.fulfil_date.ok:
                if (f := parse_fulfil_date(wide)).ok:
                    r.fulfil_date = f
            if not r.customer.ok:
                if (f := parse_customer(wide, roster)).ok:
                    r.customer = f

    validate(r)
    r.filename = build_filename(r)
    return r


def page_png(pdf_path: str | Path, dpi: int = 110) -> bytes:
    """Page 1 as PNG, for the review screen."""
    with pymupdf.open(pdf_path) as doc:
        return doc[0].get_pixmap(dpi=dpi).tobytes("png")


def main() -> int:
    """CLI contract (used for local testing only — the hosted service uses
    server.py, not this entrypoint):

        python extract.py FILE.pdf [--roster roster.txt] [--thumb out.png]

    Always prints exactly one JSON object to stdout, and always exits 0 —
    even on failure. Errors are reported in the JSON, never on stderr.
    """
    import argparse, json, sys, traceback

    ap = argparse.ArgumentParser()
    ap.add_argument("pdf")
    ap.add_argument("--roster", help="text file, one customer name per line")
    ap.add_argument("--thumb", help="also write page 1 as PNG to this path")
    ap.add_argument("--thumb-dpi", type=int, default=110)
    a = ap.parse_args()

    try:
        names = []
        if a.roster and Path(a.roster).exists():
            names = [ln.strip() for ln in
                     Path(a.roster).read_text("utf-8").splitlines() if ln.strip()]

        out = process(a.pdf, roster=names).to_dict()

        if a.thumb:
            Path(a.thumb).write_bytes(page_png(a.pdf, dpi=a.thumb_dpi))
            out["thumb"] = a.thumb

    except Exception as e:
        out = {
            "source": Path(a.pdf).name, "filename": None, "confident": False,
            "problems": [f"{type(e).__name__}: {e}"],
            "invoice": {}, "fulfil_date": {}, "customer": {},
            "ocr_dump": {"_traceback": traceback.format_exc()},
        }

    json.dump(out, sys.stdout, ensure_ascii=False)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

### `apps/ocr-service/server.py` — FastAPI wrapper (the actual hosted entrypoint)

Reuse `extract.process()` and `extract.page_png()` directly as a library — do not
shell out to the CLI from inside the container.

Required endpoints:

- `POST /parse` — multipart file upload (`file`). Reads `roster.txt` from the
  project root if present. Returns `Result.to_dict()` as JSON, **plus** a
  `"thumb"` key containing the page-1 PNG as base64 (`page_png(path, dpi=110)`).
  Must write the upload to a `tempfile.NamedTemporaryFile`, process it, and
  delete it in a `finally` block regardless of outcome.
- `GET /health` — returns `{"ocr_lang": extract.ocr_lang()}`. The Worker uses
  this to surface a warning banner if the Hungarian language pack failed to
  install (i.e. `ocr_lang() != "hun+eng"`).

Errors inside `/parse` must be caught and returned as a valid `Result`-shaped
JSON with `problems` populated — never raise a raw 500 for a corrupt/unreadable
PDF, since the Worker is expected to always get parseable JSON back.

## `apps/worker` — Hono API

Purpose: orchestrator only. It does not run OCR — it signs R2 upload URLs,
calls the `ocr-service` Container per file, streams progress to the browser,
handles rename/confirm, builds the download ZIP, and manages retention.

Required routes:

- `POST /api/upload` — accept multipart PDFs from the browser, write each to
  R2 at `staging/{batchId}/{fileId}.pdf` with a generated UUID, return the
  list of `{fileId, originalName}`.
- `GET /api/parse?batchId=...` — **SSE** endpoint. For each file in the batch,
  fetch the object from R2, `fetch()` it to the `ocr-service` Container's
  `/parse` route as multipart, and emit `data: {...ParseResult, fileId}\n\n`
  as each result arrives. Emit a final `data: {"done": true}\n\n` and close
  the stream.
- `POST /api/confirm` — body: `{ batchId, items: ConfirmItem[] }`. For each
  item: if `skip` or no `filename`, copy the R2 object to
  `review/{batchId}/{originalName}` (never overwrite — append `_2`, `_3`...
  on collision); otherwise copy to `done/{batchId}/{filename}`. Append one
  line per item to an R2-stored `undo.jsonl` log (or a small KV/D1 record —
  your choice, but it must be queryable by `batchId`). Return per-item
  results.
- `GET /api/download?batchId=...` — stream a ZIP of everything under
  `done/{batchId}/` back to the browser. Build the ZIP in the Worker
  (streaming from R2), not in the Container.
- `POST /api/batch/:batchId` (DELETE) — delete every R2 object under
  `staging/{batchId}/` and `done/{batchId}/`. This is the "delete originals"
  confirmation prompt action, called only after the browser confirms the ZIP
  download succeeded.
- `POST /api/undo` — reverse the most recent confirm batch: move objects in
  `done/` or `review/` for that batch back to `staging/`, using the undo log.
- `GET /api/health` — proxy `ocr-service`'s `/health` so the frontend can
  show an OCR-language warning banner.

R2 bucket key layout:

```
staging/{batchId}/{fileId}.pdf
done/{batchId}/{filename}.pdf
review/{batchId}/{originalName}.pdf
```

R2 lifecycle rules (configure via `wrangler.toml` or `wrangler r2 bucket
lifecycle add`, not application code):

- `staging/` prefix — expire after 7 days
- `done/` and `review/` prefixes — expire after 30 days

Auth: the entire Worker must be placed behind **Cloudflare Access**,
allow-listing exactly one email address (provided separately, not hardcoded
in source — read from an environment variable / Access policy config, not
application code). Do not implement custom password/session logic.

Container binding: define in `wrangler.toml` under `[[containers]]`, pointing
`image` at `../ocr-service/Dockerfile`, `instance_type = "standard-1"`,
`max_instances = 1`. Address it in Hono via the Durable-Object-backed
container binding (`env.OCR_CONTAINER.get(env.OCR_CONTAINER.idFromName("default"))`).

## `apps/web` — React + shadcn/ui

Layout: shadcn `SidebarProvider` + `Sidebar` (file list) + main panel (review
detail), per the following spec:

**Upload screen** (initial state, no files yet): drag-and-drop zone + file
picker, accepts only `.pdf`, multiple files. On drop, `POST /api/upload`,
then open an `EventSource` to `/api/parse?batchId=...` and populate the file
list incrementally as SSE messages arrive.

**Sidebar**: one row per file, sorted by status — red (no filename produced)
first, amber (filename produced but `confident === false`) second, green
(`confident === true`) last. Status indicated by a colored dot or shadcn
`Badge`, plus truncated filename/original name. Row click selects that file
for the detail panel. Use `SidebarMenuButton` with `isActive`.

**Detail panel** (selected file): 
- thumbnail `<img src="data:image/png;base64,{thumb}">`, click opens a
  shadcn `Dialog` with a larger version
- the three extracted fields shown read-only (`Sorszám`, `Teljesítés`,
  `Vevő`), each with a check/warning icon from `field.ok`
- `problems[]` rendered as a warning list when non-empty
- an `Input` for the filename, pre-filled from `filename` (empty if null),
  **always editable regardless of confidence**
- Confirm and Skip buttons per file
- keyboard shortcut: Enter confirms the current file and auto-advances
  selection to the next unconfirmed file in the sidebar order

**Batch actions** (footer bar, visible once any files are parsed): a summary
count ("14 ready, 2 need review"), a primary "Confirm all reviewed" button
that calls `POST /api/confirm` for every item, and after a successful
`/api/download`, a shadcn `AlertDialog` asking "Delete {N} uploaded
originals?" with Delete as the focused default action, wired to
`DELETE /api/batch/:batchId`.

Do not use a PDF.js-based viewer for the thumbnail/review flow — the PNG
from `extract.page_png()` / `/parse`'s `thumb` field is sufficient and is
already tested. A full PDF viewer library is out of scope for this pass.

## GitHub Actions — CI and tag-triggered production deploy

Two workflows. CI runs on every push/PR against `main` and never deploys.
Deploy runs **only** when a version tag is pushed, and deploys everything —
Worker, static web assets, and the OCR Container image — in one job, since
`wrangler deploy` handles the Container build/push itself when a
`[[containers]]` block is present in `wrangler.toml` (the runner needs Docker
available, which `ubuntu-latest` provides by default).

Required repo secrets (set these manually in GitHub — do not put them in any
committed file):

- `CLOUDFLARE_API_TOKEN` — scoped to Workers Scripts Edit, R2 Edit, Containers
  Edit, Access: Apps and Policies Edit (only if Access config is also managed
  via `wrangler`/Terraform — otherwise Access can stay dashboard-managed and
  this scope is unnecessary)
- `CLOUDFLARE_ACCOUNT_ID`

### `.github/workflows/ci.yml`

Triggers: `pull_request` targeting `main`, and `push` to `main`.

```yaml
name: CI

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0   # nx affected needs history to diff against

      - uses: oven-sh/setup-bun@v2
        with:
          bun-version: latest

      - run: bun install --frozen-lockfile

      - uses: nrwl/nx-set-shas@v4

      - name: Lint, test, build affected projects
        run: bunx nx affected -t lint test build --parallel=3
```

`nrwl/nx-set-shas` sets the base/head SHAs so `nx affected` correctly diffs
against the target branch instead of the whole repo — required for PRs to
only check what changed (e.g. a `web`-only PR shouldn't rebuild/test
`ocr-service`).

```yaml
jobs:

      - name: Deploy worker (includes web assets + OCR container)
        working-directory: apps/worker
        run: bunx wrangler deploy
        env:
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          CLOUDFLARE_ACCOUNT_ID: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
```

Notes for whoever (Claude Code or you) wires this up:

- The `environment: production` line only enforces a manual-approval gate if

  reviewers in the repo's Settings → Environments. Whether that protection
  rule is available depends on the plan and whether the repo is public or
